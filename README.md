# A Validity Audit of Emotion Probes in Llama 3.1 70B

> **Status: 2026-08-19.** This README supersedes the 2026-04-11 version. Several
> of its headline numbers (`CV AUC 0.997`, `LOTO 0.992`, `steering p = 0.005`) did
> not survive later controls and are retracted below, along with two claims that
> appeared in an interim August draft (a "faithfulness gap" and the
> "HIDDEN quadrant"). **Every number below is regenerated by
> `scripts/paper_numbers.py`** into `results/paper_numbers.json`; a second script,
> `scripts/check_paper_consistency.py`, gates the paper against it (119 checks).

## TL;DR

We reconstruct emotion directions in Llama 3.1 70B and test four claims about them
separately. Three cheap controls each change the answer.

| Claim | Control | Verdict |
|---|---|---|
| Directions track human emotion | EmoBank, zero-shot | **Supported** (valence R² = 0.377, n = 10,062) |
| `desperate` tracks reward hacking | **Response length** | **Refuted** — resid. AUC 0.592, max-T p = 0.91 |
| *Some* direction tracks it | **Permutation max-T over 50** | **Supported, but not the registered one** — `bored` 0.858, max-T p = 1e-4 |
| Probe beats CoT text | **ROC tie structure** | **Not evaluable** — 55.2% of pairs are ties |
| Steering causes the behavior | **Matched-norm random null** | **Refuted** at ≥2.42× (original reports ~14×) |
| Association generalizes across mechanisms | Preregistered rule | **INSUFFICIENT-DATA** |

The lesson: a probe can be semantically valid, appear behaviorally predictive
because of a trivial output property, carry real signal on a *different* axis than
hypothesized, and still provide no causal handle.

## What holds

### 1. Semantic validity (valence)

Frozen probes projected onto EmoBank (10,062 human-rated sentences), no refitting:
valence CV R² = **0.377**, arousal 0.180, dominance 0.154. Coherent sign structure
(`ecstatic` +0.38, `furious` −0.34). Supports a valence axis; does **not** establish
that any vector represents the state its label names.

### 2. A real association — on a different axis than we registered

`desperate` reaches raw AUC 0.832 against reward hacking on 120 unsteered trials,
but ρ(probe, response length) = **0.606** (p = 2.2e−13), and residualizing on
length leaves AUC **0.592 [0.412, 0.756]** — null on every criterion
(raw p = 0.269, BH q = 0.354, max-T p = 0.912).

Sweeping all 50 directions with a permutation max-T correction (10k label
permutations shared across directions, so the correction accounts for their
correlation), **7 of 50 survive family-wise at α = .05**:

| Direction | Resid. AUC | 95% CI | max-T p |
|---|---|---|---|
| `bored` | **0.858** | [0.749, 0.948] | **0.0001** |
| `nostalgic` | 0.797 | [0.636, 0.938] | 0.0027 |
| `melancholy` | 0.765 | [0.579, 0.918] | 0.0132 |
| `gloomy` | 0.761 | [0.585, 0.910] | 0.0163 |
| `lonely` | 0.760 | [0.567, 0.928] | 0.0167 |
| `compassionate` | 0.265 | [0.108, 0.447] | 0.0479 |
| `sad` | 0.734 | [0.556, 0.885] | 0.0490 |
| **`desperate`** (preregistered) | **0.592** | [0.412, 0.756] | **0.9115** |

A coherent low-arousal negative-affect cluster is positively associated with
shortcut-taking; `compassionate` is negatively associated. **This was not the
registered hypothesis.** The direction was chosen after seeing the data; only the
max-T column licenses any claim. We do not assert `bored` measures boredom — it may
index a response property we have not measured, exactly as `desperate` indexed length.

## What fails

### 3. The CoT-text comparison is not evaluable

On the pooled set (n = 992, 87 events) the V_text composite takes one modal value
for **74.0%** of trials — `frustration` is constant at 1.0 in 985/992 trials;
`urgency`/`composure` have sd 0.24/0.35 on a 1–7 scale. Consequence:
**43,485 of 78,735 (55.2%)** positive–negative ROC pairs are ties at that value,
each contributing exactly 0.5.

| | AUC | n (events) |
|---|---|---|
| V_text, all trials | 0.647 | 992 (87) |
| V_text, where it is **not** at the mode | **0.836** | 258 (22) |
| V_internal, all trials | 0.837 | 992 (87) |

Where V_text can discriminate, it matches V_internal. The apparent gap is tie
compression in a non-responsive instrument, not CoT unfaithfulness. The reported
empty middle tertile is likewise an artifact: p33 and p66 are both exactly −1.0,
so the middle bin is empty by construction.

### 4. Causal specificity fails — and the null is powered

| Condition | hacks / n | rate | vs unsteered |
|---|---|---|---|
| Unsteered baseline | 14 / 120 | 11.7% | — |
| Emotion vector @ ±0.3 | 12 / 160 | 7.5% | OR 0.61, p = 0.30 |
| 5 random orthogonal directions @ ±0.3 | 13 / 200 | 6.5% | OR 0.53, p = 0.14 |

**Emotion vs random: Fisher p = 0.835.** Neither arm differs from baseline, so this
is not capability degradation (mean response lengths 1402 / 1324 / 1456 chars).
Fine-grained dose–response flat (z = −1.42, p = 0.157); text injection null
(17.5% vs 11.7%, p = 0.417).

**MDE = 2.42× relative risk** at 80% power, α = .05. Sofroniew et al. report ~14×,
so the design **excludes the claimed magnitude** while being unable to exclude
effects below 2.42×.

## Limitations — read before reusing any number

1. **The probe's readout window includes the response.**
   `compute_emotion_probes` (`scripts/phase2_steering.py:187`) averages tokens 50 →
   end-of-sequence. Associations are **concurrent, never predictive**, and cannot
   separate measurement artifact from mediation by length. A pre-decision
   assistant-header readout exists (`src/experiments.py`) but **no released trial
   file carries it** — it needs GPU regeneration.
2. **Length residualization is linear** and would not remove a nonlinear dependence.
3. **The surviving cluster is post-hoc.** max-T controls selection, not the
   possibility that these directions index a further unmeasured property.
4. **Underpowered:** 14 events at n = 120.
5. **The diverse-mechanism dataset is unusable.** Qwen/Claude agree on only
   **165/650 (25.4%)** — Qwen: 2 SHORTCUT / 524 UNCLEAR; Claude: 194 SHORTCUT.
   All conclusions from it are withheld, including negative ones. By contrast the
   120-trial unsteered set has **120/120** agreement.
6. **We did not steer at layer 39.** The association ranges from AUC 0.450 (layer 26)
   to 0.918 (layer 39) across the sweep, while all steering was done at layer 53.
   This is the single largest gap in the causal null.
7. **Conceptual, not direct, replication:** different model, extraction, and norms
   than Sofroniew et al.
8. **Probe–task confound:** probes predict task identity at 95.4% accuracy.
9. **Task B (sycophancy) is dead:** 2 events in 650 trials. Excluded.
10. **`phaseB/` has scripts but no results.** Never run.

### Label field semantics — important

Judged `.jsonl` rows carry **three** classification fields; using the wrong one
silently changes every downstream number.

| Field | Meaning |
|---|---|
| `classification` | **Stale regex heuristic.** `unclear` for all 650 diverse rows. **Never use.** |
| `judge_classification` | Qwen 2.5 72B, 3-pass majority — used for all results above |
| `claude_classification` | Claude, 3-pass majority — cross-family check only |

Existing analysis scripts are not uniform: `analyze_phase4_judged.py` and
`analyze_faithfulness_gap_robust.py` read `judge_classification`;
`analyze_diverse_today.py` and `analyze_phase2_transfer_stats.py` read
`claude_classification`. `paper_numbers.py` uses `judge_classification` throughout.

## Methodology

```
Phase 1  50 emotion vectors from the residual stream (primary layer 53/80)
   v
Phase 2  Steering with desperate/calm at 7 strengths (-0.5 … +0.5), Task A
   v
Phase 4  CONTROLS: fine sweep (±0.05…±0.5), 5 random orthogonal directions,
         text injection, 80 extra unsteered trials, 6-layer probe sweep
   v
Judges   Qwen 2.5 72B (3-pass) + Claude (3-pass, cross-family)
   v
Audit    length control, permutation max-T over 50 directions, ROC tie analysis,
         power analysis, preregistered decision rule
```
